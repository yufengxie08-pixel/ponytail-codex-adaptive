# Codex Ponytail Core

Use the smallest sufficient implementation, not the fewest possible lines.
Understand the request and trace the touched flow before editing. Reuse code already in the project before adding abstractions, dependencies, or files. Remove repetition and speculative features, but never remove required behavior, visual quality, interaction feedback, accessibility, security, validation, error handling, or necessary extensibility. When uncertain, preserve quality and ask a focused question. A non-trivial change leaves one runnable check or test.
