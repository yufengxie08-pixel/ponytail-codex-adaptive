# Codex Game Profile

Optimize for a playable, responsive result before minimizing code. Preserve game feel, input handling, state transitions, collision rules, feedback, animation, particles, sound triggers, level data, and a sensible path for adding content. Do not replace a requested game mechanic with a placeholder or delete necessary structure because it adds lines. Reuse the engine and project patterns already present; remove only duplicate systems, dead paths, unnecessary dependencies, and speculative framework layers. Run the smallest meaningful gameplay check.
