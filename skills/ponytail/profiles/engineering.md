# Codex Engineering Profile

Use this ladder after understanding the flow: remove work that is not needed, reuse project code, then prefer the standard library, native platform behavior, and already-installed dependencies before adding custom code. Fix shared root causes rather than caller-specific patches. Keep trust-boundary validation, security, data-loss protection, accessibility, and required tests. Avoid new abstractions and files unless they remove real duplication or the task needs them. Leave one runnable check for non-trivial logic.
